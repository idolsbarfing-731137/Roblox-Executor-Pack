Yes, XCutors is an open-source collection provided free of charge. Some included executors may have their own licensing models.

### Which Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11 (64-bit). It may run on older versions but is not guaranteed.

### How do I update the collection?

Check the GitHub repository's Releases page for new versions. Download the latest installer to update all components.

### Can I add my own executor to the collection?

The universal loader supports custom executor integrations. Refer to the documentation in the 'docs' folder for configuration details.

### Why does my anticomponent flag the download?

Some security tools may flag executor-related files. This is a common false positive. You can verify the file checksums in the release notes.

### Do I need to keep the Roblox client open?

Yes, the Roblox game client must be running before you inject and use an executor through XCutors.
